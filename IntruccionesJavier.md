### Levantar backend para discapacitados

1. Abrir docker desktop
2. En la carpeta raiz en un terminal ejecutar
3. "docker compose build" una vez acabado ejecutar
4. "docker compose up" una vez acabado verificar que los dos contenedores estan levantados y funcionando viendo que el backend tiene cargado el modelo y levantado el puerto 3000 del node
5. levantar el frontend haciendo en el terminal "cd Frontend-APP" y luego "npx expo start -c"
